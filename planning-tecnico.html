Stack tecnológico

Herramientas del sistema

🛍️
Shopify
Tienda online, catálogo, pagos, gestión de pedidos. Plan Basic €27/mes.
⚙️
n8n (self-hosted)
Motor de automatización. Orquesta todos los flujos. Docker en VPS DigitalOcean.
💬
WhatsApp Business API
Respuestas automáticas 24/7 via Baileys (sin coste de API oficial inicial).
📸
Instagram Graph API
DMs automáticos cuando alguien comenta. Requiere cuenta Business verificada.
🤖
Claude API (Anthropic)
Cerebro IA conversacional. Modelo claude-sonnet. ~€0.05/conversación.
✉️
SparkPost / Bird
Emails automáticos: presupuestos, recordatorios. 500 emails/mes gratis.
🗄️
PostgreSQL
CRM de clientes, historial de conversaciones, leads. Managed DB DigitalOcean.
☁️
DigitalOcean VPS
Droplet 2GB $18/mes. Hospeda n8n, DB, dominio. Toronto (latencia España OK).
🗺️
Google My Business API
Publicación automática de posts y respuesta a reseñas. Requiere cuenta verificada.

Los 4 sprints de instalación

📋
Sprint 0 · Pre-arranque
Configuración de entorno
~6h
Infraestructura
○
Provisionar VPS DigitalOcean
Ubuntu 22.04, 2GB RAM, 60GB SSD. Instalar Docker + Docker Compose. Configurar UFW (puertos 22, 80, 443, 5678).
1h
○
Instalar n8n + PostgreSQL via Docker
docker-compose.yml con n8n + postgres + nginx. SSL con Let's Encrypt (Certbot).
1.5h
○
Configurar dominio n8n.narosasp.com
Subdominio apuntando al VPS. SSL wildcard si es posible. Verificar https funcional.
0.5h
Reunión inicial con cliente
○
Llamada 45min con la dueña
Recoger: catálogo de productos + precios, estilo visual, nº WhatsApp, tono de comunicación, horarios, preguntas frecuentes de clientes.
1h
○
Documentar base de conocimiento del bot
FAQ, precios, packs, tiempos de entrega, área de cobertura, política de devoluciones. Será el system prompt del bot.
2h
S1
Sprint 1 · Días 1–7
Tienda Shopify + SEO
~18h
Shopify Setup
✓
Crear tienda Shopify + tema premium
Tema Dawn o Sense (gratis). Colores marca: blanco, dorado, rosa Narosa. Logo + favicon. Política envíos y devoluciones.
3h
✓
Subir catálogo de productos
Mínimo 6 categorías (bouquets, columnas, packs temáticos, globos helio, menaje, decoración). Fotos HD + descripción SEO + precio. Variantes si aplica.
5h
✓
Pasarela de pago
Stripe (integración nativa Shopify). Bizum si disponible vía app. PayPal como alternativa. Test de transacción antes de live.
1h
✓
Conectar dominio narosasp.com a Shopify
CNAME @ → shops.myshopify.com. Redirigir www. SSL automático Shopify. Verificar en incógnito.
0.5h
SEO técnico (ventaja competitiva)
✓
Schema.org markup completo
LocalBusiness (nombre, dirección María Aguiló, horario, teléfono). Product schema en cada producto. BreadcrumbList en colecciones. App Shopify: Avada SEO o Yoast.
2h
✓
Meta descriptions y títulos SEO únicos
Keyword mapping: "Globos Barcelona", "Globos helio Barcelona", "Bouquets globos Gràcia", "Decoración fiestas infantiles Barcelona". Title ≤60 chars, meta ≤155 chars.
2h
✓
Alt texts en todas las imágenes
Formato: "[producto] · Narosa Sweet Party · Barcelona". Prioridad: imágenes de portada y hero. Revisar con Screaming Frog trial.
1h
✓
Sitemap + robots.txt + GSC
Shopify genera sitemap automático. Verificar en Google Search Console. Solicitar indexación de páginas clave.
1.5h
S2
Sprint 2 · Días 8–14
WhatsApp Bot + Email automático
~16h
WhatsApp bot (Baileys + Claude)
✓
Setup Baileys en VPS
Node.js 18+. Baileys v6. PM2 para proceso persistente. QR scan inicial en presencia de la dueña. Anti-baneo: delays entre msgs, no broadcasts masivos.
3h
✓
Flujo n8n: WhatsApp → Claude → respuesta
Webhook Baileys → n8n. Claude con system prompt de Narosa (productos, precios, FAQ). Memoria de conversación por número. Escalado a humano si necesario.
4h
✓
Flujo de cualificación de lead
Preguntas: fecha evento, tipo fiesta, nº personas, presupuesto, zona entrega. Al completar → trigger email presupuesto + notif a dueña.
3h
Email automático (SparkPost)
✓
Template HTML email presupuesto
Diseño Narosa: logo, colores, foto pack, desglose de precios, enlace pago Shopify. Generado dinámicamente por Claude según datos del lead.
3h
✓
Recordatorio anti-olvido (D+7)
Si no hay respuesta en 7 días → email follow-up automático. Máx 2 seguimientos. Opt-out link obligatorio (RGPD).
2h
✓
CRM básico en PostgreSQL
Tabla leads: nombre, número, fecha evento, pack interesado, estado (lead/presupuesto/cerrado). Visible para la dueña via n8n dashboard.
1h
S3

Instagram + Google My Business
~12h
Instagram automático
✓
Conectar Instagram Graph API a n8n
Meta Developer App. Permisos: pages_read_engagement, instagram_basic, instagram_manage_messages. Token de larga duración (60 días, refresh automático).
2h
✓
Flujo: comentario → DM automático
Webhook Instagram → n8n detecta palabras clave (precio, info, quiero) → DM personalizado invitando a WhatsApp para presupuesto.
3h
✓
Planificación contenido Mes 1
30 posts programados con Claude: 15 fotos de productos, 8 reels de decoración, 7 stories. Horario óptimo: mar-jue-sáb 11h y 18h. Preparar con la dueña.
4h
Google My Business
✓
Verificar y optimizar ficha GMB
Fotos actualizadas, horario correcto, descripción con keywords, URL a Shopify. Categoría: "Tienda de globos". Servicios: decoración, bouquets, helio.
1h
✓
Publicación automática semanal GMB
n8n cron job lunes 9h → Claude genera post → Google My Business API publica. Alterna ofertas, novedades y eventos. No requiere intervención manual.
2h
S4
Sprint 4 · Días 22–28
QA, Lanzamiento y Formación
~8h
Testing
✓
5 conversaciones WhatsApp simuladas
Scripts de prueba: lead frío, lead con urgencia, lead que pide precio, lead con pregunta edge case, lead que quiere cancelar. Validar respuestas y flujo.
2h
✓
Test completo de compra en Shopify
Añadir producto → pago test Stripe → confirmación email → actualización CRM. Verificar en móvil iOS y Android.
1h
✓
Test email presupuesto end-to-end
Trigger desde WhatsApp → generación Claude → envío SparkPost → recepción cliente. Verificar spam score <3. SPF/DKIM validados.
1h
Entrega y formación
✓
Sesión formación 1h con la dueña
Cómo ver los leads en el dashboard. Cómo subir productos nuevos a Shopify. Qué hacer si el bot no entiende algo. Cómo pausar el bot si viaja.
1h
✓
Lanzamiento + 48h monitorización
Anuncio en Instagram "¡Ya podéis hacer vuestros pedidos online!". Monitorizar n8n logs cada 4h las primeras 48h. Canal WhatsApp directo con dueña activo.
2h
✓
Inicio período de garantía 15 días
Soporte diario vía WhatsApp. Cualquier bug corregido en <24h. Si no funciona como prometido → reembolso total. Documentar en contrato.

Gestión de riesgos

Riesgos identificados y mitigaciones

RiesgoProbabilidadImpactoMitigación
Baneo WhatsApp por envíos masivos Media Alto Delays entre mensajes, no broadcast, responder solo a inbound. Backup: número de reserva.
Meta revoca acceso Instagram API Baja Alto Usar permisos mínimos. Token refresh automático. Modo manual de backup en n8n.
VPS caído (n8n inaccesible) Baja Medio Alerta UptimeRobot. PM2 restart automático. Backup semanal DO Snapshots.
Claude API cara (muchas conversaciones) Media Bajo Budget cap €30/mes en Anthropic. Prompt optimizado para usar pocos tokens.
Cliente no proporciona accesos a tiempo Media Medio Checklist firmado en el contrato. Sprints reordenables. Deadline máx D+14 para accesos.
